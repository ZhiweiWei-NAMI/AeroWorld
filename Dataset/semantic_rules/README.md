# Semantic rules

`profiles/` contains the current objective, stage and state-model contracts. `predicates/` defines predicate templates. `schema/` describes published records. The stage contract's inline clauses are the executable stage authority; event firing alone does not prove scientific closure.

The producer is `../semantic_truth/objective_pipeline.py`. State computations are in `../semantic_simulation/`. Contracts distinguish missing evidence from false predicates and retain actual failure outcomes. Published records trace sources by path and rule identity without integrity metadata.
